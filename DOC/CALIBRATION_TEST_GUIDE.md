## 사전 측정

### 1. 반바지 실측값 측정

반바지를 평평하게 펴고 다음 항목들을 자로 **정확히** 측정합니다:

#### 측정 항목
| 항목 | 측정 방법 | 실측값 (cm) |
|------|-----------|-------------|
| **허리둘레** | 허리 밴드 양쪽 끝 × 2 | _________ |
| **엉덩이둘레** | 엉덩이 가장 넓은 부분 × 2 | _________ |
| **총길이** | 허리 위쪽에서 밑단까지 | _________ |
| **밑위** | 허리에서 가랑이 중심까지 | _________ |

#### 측정 팁
- 📏 줄자를 당기지 않고 자연스럽게 측정
- 📐 평평한 표면에 펼쳐서 측정
- 🔄 각 항목을 3회씩 측정하여 평균값 사용
- ✍️ 소수점 첫째 자리까지 기록

#### 예시
```
허리둘레:
  1차: 78.2 cm
  2차: 78.0 cm
  3차: 78.3 cm
  평균: 78.2 cm ← 이 값을 실측값으로 사용
```

### Phase 2: 교정 수행

#### 1단계: 교정 워크플로우 시작
```
앱 → 설정 → "측정 시스템 교정" 탭
또는
측정 화면 → 디버그 모드 → "교정" 버튼
```

#### 2단계: 기준 샘플 선택
- **의류 타입**: 반바지 (Shorts)
- **측정 항목**: 허리둘레 (Waist Circumference)

#### 3단계: 실측값 입력
- 위에서 측정한 **평균 실측값** 입력
- 예: `78.2`

#### 4단계: AR 측정 (10회)
- 앱이 안내하는 대로 10회 측정
- 각 측정 간 반바지 위치를 약간씩 변경
- 일관된 카메라 각도와 거리 유지

#### 5단계: 결과 확인
앱이 자동으로 계산하여 표시:
- ✅ 평균 측정값
- ✅ 표준편차
- ✅ 오차값 (cm)
- ✅ 오차율 (%)
- ✅ 보정 계수

#### 예상 결과 예시
```
실측값: 78.2 cm
평균 측정값: 76.5 cm
오차: 1.7 cm
오차율: 2.17%
보정 계수: 1.0222
```

#### 6단계: 교정 저장
- **프로파일 이름**: "반바지 허리둘레 - 2025-11-05"
- 저장 버튼 탭

#### 7단계: 다른 측정 항목 반복
- 엉덩이둘레
- 총길이
- 밑위

각 항목마다 **별도의 교정 프로파일** 생성

## 결과 기록

### 종합 비교표

| 측정 항목 | 실측값 | 교정 전<br>평균 | 교정 전<br>오차 | 교정 전<br>오차율 | 교정 후<br>평균 | 교정 후<br>오차 | 교정 후<br>오차율 | 개선율 |
|-----------|--------|-----------------|-----------------|-------------------|-----------------|-----------------|-------------------|--------|
| 허리둘레 | _____ | _____ | _____ | _____% | _____ | _____ | _____% | _____% |
| 엉덩이둘레 | _____ | _____ | _____ | _____% | _____ | _____ | _____% | _____% |
| 총길이 | _____ | _____ | _____ | _____% | _____ | _____ | _____% | _____% |
| 밑위 | _____ | _____ | _____ | _____% | _____ | _____ | _____% | _____% |

### 계산 공식
```
오차 (cm) = |실측값 - 평균 측정값|
오차율 (%) = (오차 / 실측값) × 100
개선율 (%) = ((교정 전 오차 - 교정 후 오차) / 교정 전 오차) × 100
```

## 데이터 분석

### 1. 정확도 평가

#### 목표 정확도
- ✅ **우수**: 오차율 < 2%
- ⚠️ **양호**: 오차율 2~5%
- ❌ **개선 필요**: 오차율 > 5%

#### 분석 항목
1. **교정 전후 비교**
   - 오차율이 감소했는가?
   - 개선율은 얼마인가?

2. **일관성 평가**
   - 표준편차가 작은가? (< 1.0 cm 권장)
   - 변동 계수(CV)는? (< 5% 권장)

3. **환경 영향**
   - 환경 점수가 0.8 이상인가?
   - 깊이 품질이 0.8 이상인가?

### 2. 문제 진단

#### 오차가 큰 경우
- 📸 **촬영 거리**: 40-60cm 범위 확인
- 📐 **카메라 각도**: 수직 정렬 확인 (±10도 이내)
- 💡 **조명**: 500~2000 lumens 확인
- 🧥 **의류 상태**: 평평하게 펴졌는지 확인

#### 표준편차가 큰 경우
- 🔄 **측정 일관성**: 매번 같은 방식으로 측정
- 📏 **포인트 선택**: 정확한 위치 탭
- ⏱️ **AR 추적**: 안정적인 추적 상태 확인

### 3. 보정 계수 검증

#### 합리적 범위
- ✅ **정상**: 0.95 ~ 1.05 (±5% 이내)
- ⚠️ **주의**: 0.90 ~ 0.95 또는 1.05 ~ 1.10
- ❌ **재검토**: 0.90 미만 또는 1.10 초과

#### 재검토가 필요한 경우
1. 실측값 재확인
2. 측정 환경 점검
3. AR 초기화 후 재시도
4. 다른 반바지로 교차 검증

## 문제 해결

### Q1: 측정값이 계속 달라져요
**A**: 다음을 확인하세요:
1. AR 추적 상태가 "Normal"인지 확인
2. 카메라를 안정적으로 유지
3. 의류가 움직이지 않도록 고정
4. 환경 점수가 0.8 이상인지 확인

### Q2: 보정 계수가 이상해요 (1.5 이상 등)
**A**: 다음을 재확인하세요:
1. 실측값을 다시 측정
2. AR 측정 시 정확한 포인트 선택
3. 측정 환경 개선 (조명, 거리)
4. 다른 반바지로 교차 검증

### Q3: 교정 후에도 오차가 커요
**A**:
1. 임계값 조정 시도 (디버그 설정 패널)
2. 다른 측정 알고리즘 시도
3. 더 많은 샘플로 교정 (20회 이상)
