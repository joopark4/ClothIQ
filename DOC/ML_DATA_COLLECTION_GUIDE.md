# ML 학습 데이터 수집 가이드

**버전**: 1.0.0
**작성일**: 2025년 11월 10일
**대상**: ClothIQ 개발자 및 데이터 수집 담당자

---

## 🎯 목표

이 가이드는 ClothIQ 앱에서 고품질 ML 학습 데이터를 효율적으로 수집하는 방법을 제공합니다.

### 수집 목표
- **최소 목표**: 100개 샘플 (모델 학습 최소 요구사항)
- **권장 목표**: 1,000개 샘플 (양질의 모델 학습)
- **이상적 목표**: 5,000개 샘플 (프로덕션 수준 모델)

## 🚀 빠른 시작 (5분)

### 1. 앱 실행 및 설정
```
1. Xcode에서 ClothIQ 프로젝트 열기
2. iPhone 17 Pro 시뮬레이터 선택
3. Command + R로 실행
4. 앱 → 설정(⚙️) → ML 학습 설정
5. "학습 데이터 수집" 토글 ON
```

### 2. 첫 데이터 수집
```
1. 의류 라이브러리 → + 버튼
2. 카메라로 의류 촬영
3. 의류 타입 선택 (예: 반팔)
4. 저장된 의류 → 사진 측정 탭
5. 자동 키포인트 감지 대기 (3-5초)
6. 측정 완료
```

### 3. 확인
```bash
# 터미널에서
cd ~/Projects/ClothIQ-ClaudeCode
./scripts/test_data_collection.sh check

# 결과 예시
✅ 데이터 경로: .../MLTrainingData
📄 labels.json
   - 샘플 수: 1개
```

## 📋 상세 데이터 수집 절차

### Step 1: 환경 준비

#### 1.1 앱 설정
```
설정 → ML 학습 설정
├── ✅ 학습 데이터 수집: ON
├── ⬜ 사용자 수정 데이터만: OFF (초기에는 OFF 권장)
└── 📊 현재 샘플: 0개
```

#### 1.2 디버그 모드 활성화 (선택사항)
```
설정 → ML 학습 설정 → 디버그 모드
├── 실시간 모니터링: ON
├── 수집 상태 확인
└── 파일 시스템 확인
```

### Step 2: 의류 준비 및 촬영

#### 2.1 촬영 대상 준비
**권장 의류 배분**:
- 반팔 티셔츠: 30%
- 긴팔 티셔츠: 25%
- 반바지: 20%
- 긴바지: 20%
- 치마: 5%

#### 2.2 촬영 가이드라인

**✅ 좋은 예**:
```
- 평평한 표면에 의류 배치
- 주름 최소화
- 전체가 보이도록 촬영
- 밝은 조명
- 대비가 있는 배경
```

**❌ 피해야 할 예**:
```
- 구겨진 상태
- 일부만 보임
- 어두운 조명
- 복잡한 패턴 배경
```

### Step 3: 측정 및 데이터 수집

#### 3.1 자동 측정 (기본)
```
1. 저장된 의류 선택
2. "사진 측정" 버튼 탭
3. 자동 키포인트 감지 대기
   - 로딩 인디케이터 표시
   - 3-5초 소요
4. 감지 완료 → 자동 저장
```

#### 3.2 수동 보정 (고품질 데이터)
```
1. 자동 감지된 포인트 확인
2. 부정확한 포인트 드래그로 수정
   - 어깨 끝점
   - 소매 끝
   - 밑단 위치
3. 측정 완료 → "사용자 수정" 플래그 자동 추가
```

#### 3.3 실시간 확인
```bash
# 터미널에서 모니터링
./scripts/test_data_collection.sh monitor

# 출력 예시
📊 데이터 통계:
   총 샘플: 25개
   사용자 수정: 5개 (20.0%)
   평균 신뢰도: 78.5%
```

### Step 4: 품질 관리

#### 4.1 데이터 품질 지표

| 지표 | 불량 | 보통 | 우수 |
|------|------|------|------|
| 신뢰도 | < 60% | 60-80% | > 80% |
| 키포인트 수 | < 8개 | 8-12개 | > 12개 |
| 사용자 수정 비율 | < 10% | 10-30% | > 30% |

#### 4.2 품질 확인 명령
```bash
# 데이터 무결성 검증
./scripts/test_data_collection.sh validate

# 출력 예시
1. JSON 파일 검증...
   ✅ JSON 파싱 성공
   ✅ 모든 필수 필드 존재

2. 이미지 파일 검증...
   ✅ 모든 이미지 정상

3. 데이터 일관성 검증...
   ✅ ID 중복 없음
   ✅ 모든 키포인트 좌표 정상
```

## 🎯 데이터 수집 시나리오

### 시나리오 A: 빠른 대량 수집 (1시간, 50개)

```
목표: 다양한 의류 타입의 기본 데이터 확보

1. 준비 (10분)
   - 의류 10벌 준비 (타입별 2벌씩)
   - 촬영 공간 세팅

2. 촬영 (20분)
   - 의류당 2분 할당
   - 빠른 촬영 → 자동 저장

3. 자동 측정 (20분)
   - 각 의류 사진 측정
   - 자동 감지만 사용

4. 확인 (10분)
   - 통계 확인
   - 품질 검증
```

### 시나리오 B: 고품질 수집 (2시간, 30개)

```
목표: 사용자 수정된 정확한 데이터 확보

1. 준비 (15분)
   - 의류 6벌 신중히 선택
   - 최적 조명 세팅

2. 정밀 촬영 (30분)
   - 의류당 5분
   - 다각도 촬영

3. 수동 보정 측정 (60분)
   - 자동 감지 후 수동 보정
   - 의류당 10분

4. 품질 검증 (15분)
   - 각 샘플 검토
   - 재측정 필요 항목 식별
```

### 시나리오 C: 특정 타입 집중 (1시간, 30개)

```
목표: 특정 의류 타입 모델 개선

1. 반팔 티셔츠만 준비 (10개)

2. 다양한 조건 촬영 (30분)
   - 다른 색상
   - 다른 크기
   - 다른 각도

3. 측정 (20분)
   - 자동 + 일부 수동

4. 분석 (10분)
   - 타입별 통계 확인
```

## 💡 모범 사례

### Do's ✅

1. **일관된 환경 유지**
   - 동일한 조명 조건
   - 동일한 배경
   - 동일한 거리

2. **다양성 확보**
   - 여러 의류 타입
   - 다양한 색상
   - 다양한 크기

3. **품질 우선**
   - 흐릿한 이미지 제외
   - 일부만 보이는 이미지 제외
   - 신뢰도 낮은 데이터 재측정

4. **정기적 백업**
   ```bash
   # 매 50개 샘플마다 백업
   cp -r ~/path/to/MLTrainingData ~/backup/MLTrainingData_$(date +%Y%m%d)
   ```

5. **점진적 수집**
   - 하루 20-30개씩 꾸준히
   - 품질 확인 후 다음 배치

### Don'ts ❌

1. **품질 희생**
   - 수량만 채우려고 품질 무시
   - 동일 의류 반복 촬영
   - 검증 없이 대량 수집

2. **편향된 데이터**
   - 한 가지 타입만 수집
   - 한 가지 색상만 수집
   - 특정 크기만 수집

3. **무계획 수집**
   - 목표 없이 무작위 수집
   - 진행 상황 확인 안 함
   - 백업 없이 진행

## 🔧 문제 해결

### 문제: 데이터가 저장되지 않음

**확인 사항**:
```bash
# 1. 설정 확인
설정 → ML 학습 설정 → 학습 데이터 수집 ON 확인

# 2. 로그 확인
Xcode 콘솔에서 "MLTraining" 검색

# 3. 파일 권한 확인
ls -la ~/Library/Developer/CoreSimulator/*/Documents/
```

**해결**:
```swift
// MLTrainingDataCollector.swift 확인
if isEnabled {  // 이 값이 true인지 확인
    collectTrainingData()
}
```

### 문제: 신뢰도가 너무 낮음

**원인**:
- 흐릿한 이미지
- 복잡한 패턴
- 부적절한 조명

**해결**:
1. 더 밝은 조명 사용
2. 단색 배경 사용
3. 카메라 안정화
4. 수동으로 포인트 보정

### 문제: 특정 의류 타입만 인식 안 됨

**해결**:
1. 해당 타입 집중 수집 (최소 20개)
2. 다양한 각도/조명으로 촬영
3. 사용자 수정 비율 높이기 (50% 이상)

## ❓ FAQ

### Q: 최소 몇 개의 샘플이 필요한가요?
A: 모델 학습을 위한 최소 요구사항은 100개입니다. 하지만 실용적인 성능을 위해서는 최소 500개를 권장합니다.

### Q: 사용자 수정 데이터의 비율은 어느 정도가 적당한가요?
A: 20-30%가 이상적입니다. 너무 적으면 정확도가 떨어지고, 너무 많으면 수집 시간이 오래 걸립니다.

### Q: 한 의류를 여러 번 촬영해도 되나요?
A: 다른 각도나 조명 조건이라면 가능합니다. 하지만 완전히 동일한 조건의 중복은 피하세요.

### Q: 시뮬레이터 vs 실제 기기, 어느 것이 좋나요?
A: 시뮬레이터로 충분합니다. 실제 배포 전에만 실제 기기 테스트를 권장합니다.

### Q: 수집한 데이터를 어떻게 백업하나요?
A: `~/Library/Developer/CoreSimulator/*/Documents/MLTrainingData` 폴더를 정기적으로 백업하세요.
