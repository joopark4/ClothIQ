# 정확한 측정을 위한 팁

## 📏 실측값 측정 (줄자 사용)

### 반바지 측정 방법

#### 1. 허리둘레
```
방법 1: 밴드 측정 (권장)
1. 반바지를 평평하게 펴기
2. 허리 밴드 양쪽 끝 사이 거리 측정
3. ×2 하여 전체 둘레 계산

방법 2: 밴드 둘레 직접 측정
1. 허리 밴드를 원형으로 펴기
2. 줄자로 전체 둘레 측정
```

**예시**:
- 밴드 한쪽: 39.0 cm → 허리둘레: 39.0 × 2 = 78.0 cm

#### 2. 엉덩이둘레
```
1. 반바지를 평평하게 펴기
2. 엉덩이 가장 넓은 부분(대략 지퍼 아래 5-10cm) 측정
3. ×2 하여 전체 둘레 계산
```

#### 3. 총길이
```
1. 반바지를 평평하게 펴기
2. 허리 밴드 위쪽에서 시작
3. 밑단 끝까지 직선 거리 측정
```

#### 4. 밑위
```
1. 반바지를 평평하게 펴기
2. 허리 밴드 중앙에서 시작
3. 가랑이 솔기 교차점까지 측정
```

## 📱 AR 측정 방법

### 최적 측정 환경

#### 카메라 위치
```
거리: 40-60cm (팔을 뻗은 거리)
각도: 수직 (반바지를 위에서 내려다봄)
높이: 반바지 표면에서 40-60cm 위
```

#### 조명
```
✅ 좋은 조명:
  - 밝고 균일한 실내 조명
  - 자연광 (창문 근처)
  - 500~2000 lumens

❌ 나쁜 조명:
  - 너무 어두운 환경
  - 강한 직사광선
  - 그림자가 많은 환경
```

#### 배경
```
✅ 좋은 배경:
  - 단색 바닥 (흰색, 회색, 베이지)
  - 평평한 테이블
  - 깨끗한 표면

❌ 나쁜 배경:
  - 무늬가 복잡한 바닥
  - 반사가 심한 표면
  - 울퉁불퉁한 표면
```

### 측정 포인트 선택

#### 허리둘레
```
1. 왼쪽 허리 밴드 끝 (👈)
2. 오른쪽 허리 밴드 끝 (👉)

주의: 정확히 밴드의 양 끝을 탭
```

#### 엉덩이둘레
```
1. 왼쪽 엉덩이 가장 넓은 부분 (👈)
2. 오른쪽 엉덩이 가장 넓은 부분 (👉)

주의: 좌우 대칭되는 위치 선택
```

#### 총길이
```
1. 허리 밴드 중앙 위쪽 (👆)
2. 밑단 중앙 (👇)

주의: 중심선을 따라 측정
```

#### 밑위
```
1. 허리 밴드 중앙 (👆)
2. 가랑이 솔기 교차점 (👇)

주의: 정확한 솔기 교차점 선택
```

## 🎯 정확도 향상 팁

### 측정 전
1. **반바지 준비**
   - 구김 펴기 (다림질 권장)
   - 평평한 표면에 펴기
   - 좌우 대칭 맞추기

2. **환경 확인**
   - 디버그 모드 활성화
   - 환경 점수 확인 (> 0.8)
   - 깊이 품질 확인 (> 0.8)

3. **AR 초기화**
   - 카메라를 천천히 움직여 공간 인식
   - "평면 감지됨" 표시 확인
   - AR 추적 상태 "Normal" 확인

### 측정 중
1. **일관성 유지**
   - 매번 같은 거리에서 측정
   - 매번 같은 각도로 측정
   - 카메라 흔들림 최소화

2. **정확한 포인트 선택**
   - 확대하여 정확한 위치 확인
   - 포인트 마커가 정확히 위치하는지 확인
   - 필요 시 재측정

3. **환경 모니터링**
   - 실시간 메트릭 확인
   - 신뢰도 점수 확인 (> 0.7)
   - 카메라 거리 확인 (40-60cm)

### 측정 후
1. **결과 검증**
   - 명백히 이상한 값은 제외
   - 표준편차 확인 (< 1.0 cm)
   - 일관성 있는 값들만 사용

2. **재측정 기준**
   - 신뢰도 < 0.7
   - 이전 측정값과 2cm 이상 차이
   - 환경 점수 < 0.7

## 🔧 문제 해결

### 문제: 측정값이 너무 작게 나와요
**원인**:
- 카메라가 너무 가까움
- 포인트를 안쪽에 선택함
- 평면 투영 오류

**해결**:
1. 카메라를 50-60cm로 멀리
2. 정확히 끝점을 선택
3. 반바지를 더 평평하게

### 문제: 측정값이 너무 크게 나와요
**원인**:
- 카메라가 너무 멈
- 포인트를 바깥쪽에 선택함
- AR 추적 불안정

**해결**:
1. 카메라를 40-50cm로 가까이
2. 정확히 끝점을 선택
3. AR 재초기화

### 문제: 측정값이 매번 달라요
**원인**:
- 카메라 거리가 일정하지 않음
- 포인트 선택이 부정확함
- 환경이 불안정함

**해결**:
1. 거리 고정 (의자 등 사용)
2. 확대하여 정확히 선택
3. 조명 개선

### 문제: 신뢰도가 낮아요
**원인**:
- 조명이 부족함
- 깊이 데이터 품질이 낮음
- AR 추적 상태가 나쁨

**해결**:
1. 조명 추가
2. 카메라 거리 조정
3. AR 재초기화

## 📊 데이터 품질 체크

### 측정 전 체크리스트
- [ ] 환경 점수 > 0.8
- [ ] 깊이 품질 > 0.8
- [ ] AR 추적 상태 = Normal
- [ ] 카메라 거리 40-60cm
- [ ] 조명 500~2000 lumens

### 측정 중 체크리스트
- [ ] 신뢰도 > 0.7
- [ ] 카메라 흔들림 없음
- [ ] 포인트 마커 정확히 위치
- [ ] 거리 일정하게 유지

### 측정 후 체크리스트
- [ ] 표준편차 < 1.0 cm
- [ ] 이상치 없음
- [ ] 실측값과 비슷한 범위
- [ ] 10회 측정 완료

## 🎓 전문가 팁

### 팁 1: 여러 번 측정
```
권장: 10회 이상
최소: 5회
이유: 통계적 신뢰성 확보
```

### 팁 2: 이상치 제거
```
방법: IQR (Interquartile Range) 사용
1. 측정값을 정렬
2. Q1 (25%), Q3 (75%) 계산
3. IQR = Q3 - Q1
4. 이상치 = Q1 - 1.5×IQR 또는 Q3 + 1.5×IQR 밖의 값
```

### 팁 3: 교정 계수 검증
```
방법: 다른 반바지로 교차 검증
1. A 반바지로 교정
2. B 반바지로 측정
3. 실측값과 비교
4. 보정 계수 유효성 확인
```

### 팁 4: 환경 최적화
```
최적 조건:
- 시간: 낮 (자연광)
- 장소: 밝은 실내
- 배경: 흰색 테이블
- 거리: 50cm (팔 길이)
- 각도: 정확히 수직
```
