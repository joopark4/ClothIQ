## 최신 확인 (2026-05-08)

- 이 이슈의 원인인 `@State` 기반 ViewModel 보관 문제는 해결된 상태를 유지합니다.
- 현재 `PhotoMeasurementViewModel`은 기능별 extension으로 분리되어 있으며, 사진 측정 액션과 키포인트 처리는 `PhotoMeasurementViewModel+Actions.swift`, `PhotoMeasurementViewModel+Keypoint.swift`로 관리합니다.
- 이후 발견된 ML ON 앵커/라인 위치 문제는 별도 좌표 변환 및 타입별 keypoint 매핑 수정으로 처리했습니다.
- 관련 회귀 테스트: `ClothIQTests/PhotoMeasurementDisplayTests.swift`, `ClothIQTests/MLFeatureTests.swift`

## 문제 현상

### 증상
- 사용자가 사진을 터치하여 측정 포인트를 추가해도 화면에 아무것도 표시되지 않음
- 측정 앵커(빨간 점), 연결선(파란 선), 거리 값이 모두 보이지 않음
- 하단의 저장 버튼도 표시되지 않음

### 백엔드 로그 분석
```
✅ [PhotoMeasurement] 앵커 추가됨 - 총 개수: 1
🔢 [PhotoMeasurement] anchorsVersion 증가: 1
📐 [MeasurementAnchorsOverlay] body 호출됨 - anchors.count: 0  // ⚠️ 문제!
```

- **백엔드**: 터치 이벤트 감지 ✅, 앵커 추가 ✅, 거리 계산 ✅
- **UI**: 앵커 개수가 여전히 0개로 표시됨 ❌
- **결론**: SwiftUI가 ViewModel의 상태 변화를 감지하지 못함

## 근본 원인

### 잘못된 코드 (PhotoMeasurementView.swift:22)

```swift
// ❌ 잘못된 사용
@State private var viewModel: PhotoMeasurementViewModel?
```

### 문제점

**@State 속성 래퍼의 한계:**
- `@State`는 구조체(struct) 같은 **값 타입(value type)**을 위한 것
- `ObservableObject` 클래스의 `@Published` 프로퍼티 변경을 감지하지 못함
- 객체 참조는 저장하지만, **내부 프로퍼티 변경은 무시함**

**PhotoMeasurementViewModel 구조:**
```swift
@MainActor
final class PhotoMeasurementViewModel: ObservableObject {  // ObservableObject
    @Published var measurementAnchors: [MeasurementAnchor] = []  // @Published
    @Published var currentMeasurementResult: MeasurementResult?
    // ...
}
```

### 왜 작동하지 않았나?

1. `measurementAnchors` 배열에 앵커가 추가됨
2. `@Published`가 변경 알림을 보냄
3. 하지만 View는 `@State`로 선언되어 있어 알림을 무시함
4. SwiftUI는 뷰를 다시 그리지 않음
5. **결과**: UI가 업데이트되지 않음

## 해결 방법

### 1. PhotoMeasurementView.swift 수정

```swift
// Before ❌
@State private var viewModel: PhotoMeasurementViewModel?

init(item: ClothingItemModel) {
    self.item = item
}

var body: some View {
    Group {
        if viewModel != nil {
            mainContent
        } else {
            ProgressView("로딩 중...")
                .onAppear {
                    let vm = PhotoMeasurementViewModel(...)
                    self.viewModel = vm
                }
        }
    }
}
```

```swift
// After ✅
@StateObject private var viewModel: PhotoMeasurementViewModel

init(item: ClothingItemModel, modelContext: ModelContext) {
    _viewModel = StateObject(wrappedValue: PhotoMeasurementViewModel(
        item: item,
        modelContext: modelContext
    ))
}

var body: some View {
    mainContent
        .onAppear { ... }
}
```

### 2. ClothingDetailView.swift 수정

```swift
// Before ❌
.fullScreenCover(isPresented: $showingPhotoMeasurement) {
    PhotoMeasurementView(item: item)
}

// After ✅
.fullScreenCover(isPresented: $showingPhotoMeasurement) {
    PhotoMeasurementView(item: item, modelContext: modelContext)
}
```

### 3. PhotoMeasurementViewModel.swift 수정

```swift
// Before ❌
private let item: ClothingItemModel

// After ✅
let item: ClothingItemModel  // View에서 접근 가능하도록 public으로 변경
```

### 4. Preview 코드 수정

```swift
// Before ❌
#Preview {
    let config = ModelConfiguration(isStoredInMemoryOnly: true)
    let container = try! ModelContainer(for: ClothingItemModel.self, configurations: config)
    let item = ClothingItemModel(...)
    container.mainContext.insert(item)

    return NavigationStack {
        PhotoMeasurementView(item: item)
    }
}

// After ✅
#Preview {
    @Previewable @State var container: ModelContainer = {
        let config = ModelConfiguration(isStoredInMemoryOnly: true)
        let container = try! ModelContainer(for: ClothingItemModel.self, configurations: config)
        let item = ClothingItemModel(...)
        container.mainContext.insert(item)
        return container
    }()

    let item = try! container.mainContext.fetch(FetchDescriptor<ClothingItemModel>()).first!

    NavigationStack {
        PhotoMeasurementView(item: item, modelContext: container.mainContext)
    }
}
```

- **결론**: `@State`가 `@Published` 변경을 감지하지 못하는 것이 원인

## 교훈

### SwiftUI 속성 래퍼 선택 가이드

| 속성 래퍼 | 용도 | 예시 |
|-----------|------|------|
| `@State` | 간단한 값 타입 | `Int`, `String`, `Bool` |
| `@StateObject` | View가 소유하는 ObservableObject | ViewModel 생성 |
| `@ObservedObject` | 외부에서 전달받은 ObservableObject | 부모→자식 전달 |
| `@Binding` | 양방향 바인딩 | 값 공유 |

### 핵심 원칙
- **`ObservableObject` + `@Published` = 반드시 `@StateObject` 또는 `@ObservedObject` 사용**
- **`@State`는 단순 값 타입만!**
- View가 ViewModel을 소유하고 생성한다면 `@StateObject` 사용
- 외부에서 전달받은 ViewModel이라면 `@ObservedObject` 사용
