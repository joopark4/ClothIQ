# ML 데이터 수집 빠른 참조 카드

> 🎯 **이 문서를 인쇄하여 데이터 수집 시 참고하세요**

---

## ⚡ 5분 빠른 시작

```bash
# 1. 앱 실행
Xcode → Run (Cmd+R)

# 2. 설정
설정 → ML 학습 설정 → 수집 ON

# 3. 촬영
라이브러리 → + → 촬영 → 타입 선택

# 4. 측정
의류 선택 → 사진 측정 → 자동 감지

# 5. 확인
./scripts/test_data_collection.sh check
```

## 📱 앱 내 빠른 접근

### 설정 경로
```
홈 → 설정(⚙️) → ML 학습 설정
├── 데이터 수집: ON/OFF
├── 상세 통계 보기
├── CreateML 내보내기
└── 디버그 모드 (DEBUG only)
```

### 측정 플로우
```
1. 의류 라이브러리
2. 의류 선택 (탭)
3. 사진 측정 버튼
4. 자동 감지 (3-5초)
5. (선택) 포인트 드래그 수정
6. 완료
```

## ⚠️ 주의사항 (암기!)

### ✅ DO
1. **일관된 환경** 유지
2. **다양한 의류** 수집
3. **정기적 백업** (50개마다)
4. **품질 우선** 원칙
5. **진행 상황** 기록

### ❌ DON'T
1. 같은 의류 **중복** 촬영
2. 흐린 이미지 **방치**
3. 한 타입만 **편중**
4. 검증 없이 **대량** 수집
5. 백업 없이 **진행**

## 🆘 문제 발생 시

### 1. 데이터 저장 안 됨
```
설정 → ML 학습 → 수집 ON 확인
Xcode 콘솔 → "MLTraining" 검색
```

### 2. 신뢰도 너무 낮음
```
- 조명 개선
- 배경 단순화
- 수동 보정 증가
```

### 3. 앱 크래시
```
- 메모리 정리 (앱 재시작)
- 시뮬레이터 리셋
- Xcode 클린 빌드
```
